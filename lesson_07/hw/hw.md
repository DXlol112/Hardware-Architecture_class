## Решение

### 1. Выбор набора

**1.1.** Подходят все наборы.

**1.2.** B и C не обеспечивают расширения.

**1.3.** Расчёт потребления:

- A: 181 + 200 + 50 = **431 Вт**.
- B: 142 + 200 + 50 = **392 Вт**.
- C: 117 + 115 + 50 = **282 Вт**;

По мощности 650 Вт хватает всем.

**1.4.** Выбираю **A**

- VRM 12+1 распределяет нагрузку CPU до 181 Вт между фазами;
- B760 поддерживает разгон памяти через XMP;
- Два M.2 Key M, дополнительный x4 и два x1 дают запас.

### 2. Линии PCIe

**2.1.** Для A

| Устройство | Слот | Источник линий | Версия PCIe | Линий |
|---|---|---|---|---|
| RTX 4070 | Основной PCIe x16 | CPU | Слот 5.0, работа 4.0 | 16 |
| NVMe №1 | Первый M.2 Key M | CPU, предположительно | 4.0 | 4 |
| Звуковая карта x1 | Свободный PCIe x1 | Chipset, типично | Зависит от карты и слота | 1 |
| NVMe №2 | Второй M.2 Key M | Chipset, предположительно | 4.0 | 4 |

**2.2.** Да, Да, на скорости x1. Правило: слот может работать на меньшей скорости, чем физический размер (x16 → x4/x1), но не наоборот (x1 → x4/x16).

**2.3.** SSD, сеть и USB чипсета делят канал **DMI 4.0 x4** до CPU: около 7,9 ГБ/с в каждом направлении до накладных расходов. При большой суммарной нагрузке он ограничит обмен.

**2.4.** SSD Key M напрямую в Key E не устанавливается: отличаются ключ и назначение, нет обычного подключения к PCIe x4 для SSD.

### 3. Питание и VRM

**3.1.** Дежурные +5V → нажатие Power → плата активирует PS_ON# → БП включает основные напряжения. Если PWR_OK не появляется, CPU остаётся в сбросе: POST и загрузка не начинаются, хотя вентиляторы могут вращаться.

**3.2.** Большее число фаз распределяет ток, уменьшает нагрев каждой фазы и пульсации напряжения. Слабый VRM 6+1 при 181 Вт может перегреться и вызвать троттлинг или отключение.

**3.3.** Только EPS 8-pin обычно достаточно для штатных 181 Вт, если это допускает руководство платы. Дополнительный 4-pin распределяет ток и снижает нагрев контактов при высокой нагрузке.

**3.4.** ATX 24-pin питает плату: +3,3 В, +5 В, +12 В, −12 В, +5VSB и управляющие сигналы. EPS 8-pin подаёт +12 В на VRM процессора. CPU получает пониженное напряжение от VRM; напрямую подавать ему напряжения БП нельзя. Путь через 24-pin не рассчитан на замену выделенного питания CPU.

### 4. Память

**4.1.** Без XMP память запускается по совместимому JEDEC-профилю из SPD, а не обязательно на 6000 CL30. Возможно **DDR5-4800 CL40**.

**4.2.** Четыре модуля займут все четыре DIMM. Два модуля на канал сильнее нагружают IMC: меньшая скорость и более свободные тайминги. 6000 MT/s не гарантируются, четырёхканальной память не станет.

**4.3.** DDR4 в DDR5 DIMM не подходит: другое положение ключа, напряжения и электрическая организация, несмотря на одинаковые 288 контактов.

**4.4.** UEFI подбирает задержки, уровни сигналов и другие параметры обмена с RAM. При неудаче профиля возврат к безопасным параметрам. Единой скорости JEDEC нет: типичный безопасный режим — 4800 MT/s, но значение зависит от модулей, CPU и числа планок.

### 5. Smart-технологии

**5.1.** Две технологии:

- **Smart Fan:** пример кривой CPU — 30% до 40 °C, 60% при 65 °C, 100% при 85 °C; минимальные обороты должны обеспечивать устойчивое вращение.
- **Zero RPM:** остановка поддерживающих её вентиляторов GPU или корпуса при низкой температуре, например ниже 40 °C, запуск выше 50 °C. Разные пороги предотвращают частые переключения; CPU_FAN лучше не останавливать.

**5.2.** У Intel Adaptive Voltage меняет напряжение вместе с режимом CPU; отрицательное смещение снижает потребление и нагрев. Где то: −5…−10 °C при сохранении частот.

**5.3.** Если плата поддерживает Flashback: скачать BIOS для точной модели и ревизии, распаковать и переименовать по инструкции, скопировать в корень FAT32-флешки. Подключить ATX/EPS, включить БП, оставив ПК выключенным; вставить флешку в специальный USB, нажать Flashback и дождаться окончания индикации, не отключая питание.

**5.4.** Zero RPM задаёт остановку в холодной области, Smart Fan — обороты после запуска. Нужны подходящий датчик и разница порогов включения/выключения. Если запуск зависит от VRM, а порог выше его критической температуры, возможны перегрев, троттлинг или отключение раньше старта вентилятора.

### 6. Диагностика

| № | Диагноз | Решение |
|---|---|---|
| 6.1 | Противоречие условию: корпус поддерживает mATX | Проверить модель корпуса, стойки и препятствия |
| 6.2 | Во втором слоте GPU получает лишь x4 и работает через чипсет | Переставить в основной CPU PCIe x16 |
| 6.3 | Четыре модуля перегружают IMC на частоте профиля | запуск на JEDEC; для высокой скорости — комплект 2×32 ГБ |
| 6.4 | VRM не справляется с длительной нагрузкой | Улучшить обдув, ограничить мощность CPU либо выбрать плату с подходящим VRM |

### 7. Схема сборки A

```text
БП 650 Вт
├─ ATX 24-pin → основное питание платы B760 ATX
├─ EPS 8-pin → VRM 12+1 → Core i5-13600K (LGA1700)
└─ 12VHPWR / штатный адаптер PCIe → RTX 4070

CPU
├─ основной PCIe x16 → RTX 4070: PCIe 4.0 x16, без канала чипсета
├─ первый M.2 Key M → NVMe №1: PCIe 4.0 x4 (*)
├─ DIMM A2/B2 → 2×16 ГБ DDR5, по руководству платы
└─ DMI 4.0 x4 → B760
                 ├─ второй M.2 Key M → будущий NVMe №2, 4.0 x4 (*)
                 ├─ свободный PCIe x1 → звуковая карта x1 (*)
                 └─ сеть, USB, SATA

Кулер CPU → CPU_FAN 4-pin
Вентиляторы корпуса → SYS_FAN 4-pin
4-pin: питание, земля, контроль оборотов и управление PWM.
```

Ограничения:

- Деление M.2 с SATA или отключение слотов в условии нет.
- EPS для питания видеокарты не подходит..
- Все устройства чипсета делят DMI
- Проверить крепление и высоту кулера, длину GPU и обдув VRM.

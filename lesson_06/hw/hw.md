## Решение

1. Сравнение HDD и SSD:

   | Параметр | HDD | SSD |
   | --- | --- | --- |
   | Принцип работы | Магнитные головки читают и записывают данные на вращающихся дисках. | Данные хранятся в микросхемах флеш-памяти. |
   | Скорость чтения/записи (примерно) | 80–250+ МБ/с. | SATA: 400–550 МБ/с; <br>NVMe: 1500–14000 МБ/с. |
   | Наличие движущихся частей | Есть. | Нет. |
   | Устойчивость к ударам | Низкая, особенно во время работы. | Высокая по сравнению с HDD. |
   | Уровень шума | Шумит и может вибрировать. | Бесшумный. |
   | Цена за 1 ТБ | Обычно ниже. | Обычно выше. |
   | Срок службы / ограничения | Ограничен износом механики и условиями работы. | Ограничен ресурсом перезаписи ячеек и условиями работы. |
   | Пример использования | Архивы, фильмы, резервные копии. | Операционная система, программы, игры. |

2. Определения терминов:

   - **DDR (Double Data Rate)** — передача данных дважды за один такт.
   - **DIMM (Dual In-line Memory Module)** — планка оперативной памяти, которая устанавливается в разъём на материнской плате.
   - **Ранг (rank)** — группа микросхем на планке памяти, которые работают вместе как один блок. На планке может быть несколько рангов.
   - **CAS Latency (CL)** — число тактов от команды чтения до получения первых данных из уже открытой строки памяти.
   - **Тайминги** — задержки между операциями памяти, выраженные в тактах.
   - **Двухканальный режим** — работа памяти через два канала одновременно. Увеличивает пропускную способность.
